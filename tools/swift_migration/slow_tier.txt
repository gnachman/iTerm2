# The slow test tier: the tests the fast tier leaves out. Every other test

# runs (docs/swift-migration/test-speed.md section 2, test-tiers.md). The full
# suite runs everything, these included.
#
# Format: "Class" or "Class/testMethod", white space, the reason (required).
# tools/swift_migration/test_tiers.py reads it ("skip-args" turns it into
# xcodebuild -skip-testing: arguments; "budget" reports stale entries and the
# fast tier's tests that are still at or over one second; "propose" prints
# lines for those; "propose-removals" lists timing entries that no longer
# take a second). Moving a test here is allowed and is visible in this
# file's diff (test-speed.md section 3); it does not fix the test.
#
# The timings are the per-test median and maximum over 21 full-suite runs of
# 2026-11-20 with the address sanitizer (tools/run_tests.expect -parallel),
# from test_tiers.py; test-tiers.md lists the logs. The fast tier runs
# without the sanitizer, where many of these tests are faster, so the timing
# entries are expected to shrink once enough runs of fast_tests.sh --no-skip
# exist (test-tiers.md section 3).
