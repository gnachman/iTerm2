Version TBD (unreleased; built off master)

New Features:
- On an HDR display, text in the focused pane
  can glow brighter than normal white so it
  stands out, even in bright light. Turn on
  “HDR text in focused pane” in Settings >
  Profiles > Colors. It only applies over a
  dark background.

Improvements:
- Downloading and uploading files with scp and
  the SSH integration now read your ssh config
  the way ssh does, including Include and Match
  lines, so hosts set up by tools like Lima
  resolve correctly. Match exec blocks never
  apply, because iTerm2 won’t run commands from
  your config. Issue 13219.

Bug Fixes:
- A floating Session Note could be drawn behind
  the Clippings panel. It now stays on top.
