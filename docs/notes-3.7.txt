Version TBD (unreleased; built off master)

New Features:
- Quick Look on a web link can use the built-in
  browser, so sites you sign in to stay signed
  in. It can also open when you hover over a
  link (or hold ⌘ while hovering), for domains
  you list. Set this up in Settings > Pointer >
  Preview links on hover > Configure…, or add
  a domain when iTerm2 offers to after you rest
  on one of its links.
- A workgroup’s browser session can follow a
  variable: put \(user.browserURL) in its URL in
  Settings > Arrangements > Workgroups, and the
  browser goes wherever the variable points. A
  program in another session of the workgroup
  sets it with
  “it2 session set-var --peer-name Browser
  user.browserURL URL”. The Claude Code
  Integration’s setup has a new optional step
  that adds a browser to the Claude Code
  workgroup, so Claude can show the issue or
  pull request it is working on, including when
  Claude runs on a host reached through SSH
  Integration. Resuming the conversation brings
  the page back.
- With the Claude Code integration installed,
  iTerm2 remembers which Claude Code or Codex
  conversation was running in each session. If
  a restart ends it, such as rebooting your Mac,
  the restored session offers to resume the
  conversation. Resume All resumes every one at
  once. Issue 13171.
- Tabs can show several lines of information,
  such as the directory, the running job, and
  its status. Turn on “Show rich tab content” in
  Settings > Profiles > Window, then click Rich
  Tab Content… to choose the lines. It applies
  to windows created with that profile.
- A new built-in function,
  iterm2.escape_html(string:), makes text safe
  to use in HTML, such as an HTML tab title.
- A vertical tab bar has a search field at the
  top. Typing in it hides tabs whose title,
  lines, or tab group name don’t match. Return
  selects the first match and Esc shows every
  tab again.
- A button beside that search field shows a
  vertical tab bar’s tabs in your order, in a
  section for each status, or in a section for
  each working directory. The window’s own tab order doesn’t
  change.
- On an HDR display, text in the focused pane
  can glow brighter than normal white so it
  stands out, even in bright light. Turn on
  “HDR text in focused pane” in Settings >
  Profiles > Colors. It only applies over a
  dark background.
- Shift-click a tab to select it and every tab
  between it and the current one, as in Chrome.
  Right-click one of the selected tabs and choose
  Add Tabs to Group to put them all in a new or
  existing tab group.

Improvements:
- Saving a window arrangement can remember
  which desktop (Space) each window is on: turn
  on “Reopen windows on the desktops they’re on
  now” when you name it. Restoring it puts each
  window back on its desktop, or on the desktop
  with the same number if that one was closed.
  If there aren’t enough desktops, iTerm2 waits
  while you add them in Mission Control.
  Issues 5741 and 11895.
- Tab groups look quieter in the Minimal theme.
  A group’s name sits in a small tinted capsule
  instead of a solid full-height block, and a
  thin strip in the group’s color runs under its
  tabs. A collapsed group shows its tab count in
  a badge.
- Downloading and uploading files with scp and
  the SSH integration now read your ssh config
  the way ssh does, including Include and Match
  lines, so hosts set up by tools like Lima
  resolve correctly. Match exec blocks never
  apply, because iTerm2 won’t run commands from
  your config. Issue 13219.
- You can now choose the colors of session
  statuses, such as Claude Code’s “working”,
  “waiting”, and “idle”. In the Session Status
  tool’s settings, each priority pattern has a
  Dot and a Text color well. Leave a well empty
  to keep the color the program chose. Issue
  13130.
- Saved window state takes much less disk space
  for sessions with long scrollback history, so
  restoring windows at launch is faster. Issue
  9360.
- Switching away from iTerm2 no longer stalls
  as long when you have many sessions or long
  scrollback with Shell Integration. Saving
  window state for restoration now skips what
  hasn’t changed and writes less to disk.
- HTML tab titles, and text that scripts show
  in the status bar, can color text with
  <font color=#rrggbb>, and understand &gt;,
  &quot;, and &#39;.
- A collapsed tab group shows an icon when one
  of its tabs needs attention, such as a status
  dot, a bell, or new output.
- A tab’s context menu can snooze it, as the
  Session Status tool can snooze a session: its
  status dims and it stops asking for attention
  until the status changes.
- The GPU renderer uses much less CPU while a
  session sits idle. Issue 8640.

Bug Fixes:
- With tabs on the left or right, clicking a
  collapsed tab group at the end of the tab bar
  moved the window instead of expanding the
  group. Fixed.
- Paths and URLs no longer absorb the
  full-width punctuation that follows them in
  Chinese and Japanese text, so ⌘-click opens
  the right file or link.
- Since 3.7.8, an inline image could turn into
  a brown rectangle once it scrolled into
  history, if a lot of output arrived at once
  (as when printing a long file) or the screen
  was cleared or reset. Images now stay until
  they leave the scrollback buffer. Issue
  13235.
- When a program turned on light/dark mode
  change reports and exited without turning
  them off, text like 997;1n appeared at the
  prompt each time you switched between light
  and dark mode. iTerm2 now offers to turn the
  reports off, and turns them off when shell
  integration sees the host change. Issue
  13228.
- A floating Session Note could be drawn behind
  the Clippings panel. It now stays on top.
- Saving settings to a custom folder and Export
  All Settings and Data failed if any profile
  had a hotkey of Control-Space recorded, even a
  disabled one. Fixed.
- With Find open, clicking a command in the
  terminal no longer scrolls the view to the
  first match in that command.
- Double-click selection now finds a match for
  the “Characters considered part of a word”
  regular expression when it continues onto the
  next line of soft-wrapped text.
- Fix crashes and hangs caused by certain control
  sequences and inline images with very large
  counts or sizes. A program’s output could
  crash iTerm2 or freeze its window. Sequences
  that move the cursor, insert, delete, or erase
  characters or lines, or fill or erase a
  rectangle now stop at the edge of the screen
  as they do for smaller counts.
- The control sequence that deletes characters
  now deletes the one under the cursor when the
  cursor has been moved to the last column, and
  the one that copies a rectangle puts the copy
  at the requested row and column instead of
  swapping them, measured from the margins when
  origin mode is on.
- The control sequence that reports a checksum
  of part of the screen (off by default) now
  always sends four hex digits; some checksums
  came out as eight. It also no longer counts
  the right half of a wide character or the
  cells a tab skipped over, so screens with
  those give different checksums than before.
- An inline image more than 255 rows tall is
  limited to 255 rows, and is now narrowed to
  match. Before, it took up extra columns.
- An inline image too wide for the space right
  of the cursor is now shrunk to fit that
  space. Before, it could be cut off.
- Toasts, Global Search, Instant Replay,
  autocomplete popups, and the About window now
  follow the theme: light under the Light
  themes, dark under the Dark themes, and under
  the Minimal theme, light or dark to match the
  current session’s background color. Toasts
  used to always be dark.
- If iTerm2 ran out of file descriptors, the
  Python API stopped accepting connections until
  you restarted it. Also, AI agent hooks no
  longer open connections that iTerm2 will reject
  when a busy Mac is slow to check their
  permission. Issue 13230.
- Checkmarks in the Captured Output tool are
  now kept when windows are restored.
- Double-clicking a line in the Captured Output
  tool did nothing when the Capture Output
  trigger’s command used session variables.
- A program using the kitty image protocol could
  have iTerm2 read files in /etc and /var/db,
  which iTerm2 meant to refuse, and iTerm2’s
  replies told the program, even one on a
  remote host, why a file could not be shown,
  such as that it did not exist. Those files
  are now refused, and every file that can’t be
  shown gets the same reply.
- On a host where you installed the Claude Code
  integration over SSH Integration, starting
  Claude Code from any other terminal blocked
  every prompt with “not running under iTerm2
  SSH integration.” The status hook now does
  nothing when it can’t reach iTerm2. Reconnect
  to the host with SSH Integration to get the
  fix. Issue 13236.
- A Select Menu Item key binding whose menu
  item was disabled could fire a different menu
  item with the same title, such as an Action
  named after it. It now does nothing.
- A program using the kitty image or kitty drag
  and drop protocol could make iTerm2 type text
  of its choosing at the shell prompt, which
  ran as a command if you pressed Return.
  iTerm2’s replies to these programs no longer
  include text the program sent.
- With “Terminal may report window title”
  turned on, a program could set a title that,
  when reported back, left a command such as
  “x && rm file” at the shell prompt, which ran
  if you pressed Return. Reported titles now
  have shell punctuation such as &, $, and
  quotes replaced with spaces.
- If a profile was missing one of its text,
  background, or selection colors, colors
  changed during an SSH Integration session
  were not put back when it ended, and a
  restored session lost the colors saved with
  XTPUSHCOLORS.
- Right-to-left text no longer flashes
  unreordered while a program that uses
  synchronized updates (such as Claude Code)
  repaints the screen. Thanks to Nimanou
  (nuved) for the fix.
- Changing the theme could freeze iTerm2 for a
  long time after many tabs had been opened,
  even ones already closed. Issue 13233.
- A background color with separate light and
  dark mode values (SGR 48:12 or 48:13) used
  the light value in dark mode in cells that
  were erased, scrolled in, or added by making
  the window bigger. Issue 13231.
- In protected mode, erasing a line or the
  screen skipped the last column, and erasing
  up to the cursor left the cursor’s cell.
- When an AI agent hook was stopped before it
  finished, its entry in the Script Console
  stayed “running” forever, so with many busy
  sessions they piled up without limit.
  Issue 13183.
- Installing Shell Integration again after
  switching away from the session’s tab while the
  Internet-Free install was still running now
  stops the earlier install and lets it return
  you to your own shell first, as clicking
  Cancel does, instead of running alongside it
  and finding you inside its helper shells.
- When a restored session’s saved profile was
  damaged (by the bug in iTerm2 3.5.7), iTerm2
  offered Assign Profile even when there was no
  saved arrangement to repair, and choosing a
  profile then crashed iTerm2. The offer now
  appears only for sessions restored from a
  saved arrangement.
- Programs that track the mouse, such as
  Claude Code, now get the right cell when you
  click or drag on right-to-left text. Before,
  they got the column the mouse was in, so
  selecting Persian text selected something
  else. Thanks to Nimanou (nuved) for the fix.
- With the GPU renderer, part of an inline
  image, such as the blue line in the
  “Session Restarted” banner, could stay a
  brown block after the image became
  available.
