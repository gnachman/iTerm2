Version TBD (unreleased; built off master)

Major New Features:
- Grok is now a built-in AI provider. Pick it
  in Settings > General > AI and enter an xAI
  API key to chat with grok-4.7.

New Features:
- Control-Tab Switcher: holding the modifier
  for Cycle Tabs Forward or Backward (Control-Tab
  by default) can show the window’s tabs, most
  recently used first, with each tab’s icon,
  status, and when you last saw it, plus a
  preview of the highlighted tab. Release the
  modifier to switch. Turn it on in Settings >
  Appearance > Tabs. Based on a contribution by
  Oleh (kopyl).
- iTerm2 is now translated into Spanish, French,
  Traditional Chinese, Italian, Turkish, Polish,
  Vietnamese, Dutch, Swedish, Danish, Norwegian
  Bokmål, Finnish, Czech, Slovak, Slovenian,
  Croatian, Hungarian, Romanian, Greek, Ukrainian,
  Indonesian, Malay, Hindi, Thai, Catalan,
  Cantonese, British English, Australian English,
  Canadian English, Indian English, Canadian
  French, Latin American Spanish, and Traditional
  Chinese (Hong Kong). They are used when one of
  them is your preferred language in System
  Settings > General > Language & Region.
- iTerm2 > Suppressed Alerts lists most alerts
  and announcements at the top of a session that
  are no longer shown because you chose “Never,”
  “Always,” “Don’t Ask Again,” or a similar
  option. Select one and click Un-suppress to see
  it again.
- Session > Move Session > Move Session to
  Floating Pane turns a split pane into a
  floating pane, and a pane’s context menu has
  it too. The Floating Panes menu is now under
  Window > Split Pane and can cycle among them.
  In tmux integration, floating a pane needs
  tmux 3.8.
- The Code Review session’s toolbar in the
  Claude Code workgroup has a model picker.
  Choose Fable, Opus, Sonnet, Haiku, or type any
  model name; the next review uses it. Click the
  star beside it to make that model the default
  for new workgroups.
  To use it in a custom review command, add the
  Code Review Model toolbar item and put
  \(codeReviewModelFlag) in the command.
- it2 session add-clipping now prints the new
  clipping’s ID, and the new it2 session
  delete-clipping removes a clipping by its ID.
  Code Review tells Claude Code to use it to
  withdraw findings it no longer stands by.
- A new key binding action, Set Character
  Encoding, switches the current session’s
  character encoding with one keystroke. Find it
  under Profile in the key binding editor.

Improvements:
- Fetch Models in the manual AI model editor now
  lists the models on OpenAI- and
  Anthropic-compatible servers such as vLLM, LM
  Studio, and llama.cpp, not just Ollama.
- A manual AI model’s URL can now be a base URL
  such as http://localhost:8000/v1, or a
  gateway’s Anthropic-compatible base URL such
  as https://api.z.ai/api/anthropic. iTerm2 adds
  the endpoint for the chosen API (for example
  /chat/completions or /messages). This applies
  to existing models too: a URL with no path, or
  one ending in a version like /v1, /anthropic,
  or /openai, now gets the endpoint added.
- Tab groups of tmux Integration tabs are now
  remembered by the tmux session, so they come
  back with their names and colors when you
  detach and reattach.
- The window that shows a software update
  downloading and installing can be minimized, so
  it no longer has to sit in front of your
  terminals until you are ready to relaunch.
  Once the update is ready, you can also close
  the window and the update installs the next
  time you quit iTerm2.
- If automatic updates ever stop working, iTerm2
  can still let you know a new version is available
  and offer a link to download it.
- An update download that loses its network
  connection now picks up where it left off, or
  starts over, instead of failing with “An error
  occurred while downloading the update.” Issue
  13199.
- In a Session Note, Shift-Return now inserts a
  newline instead of collapsing the note. Press
  Escape to collapse it and return to the
  terminal.
- The tmux Dashboard now selects the session
  you’re attached to when it opens, shows a
  spinner while it loads the list of windows,
  and shows a gray checkmark next to sessions
  that another tmux connection is attached to.
- Hosts you allowed to use it2 over SSH are now
  managed in Settings > General > Magic > Manage
  Permissions, on a tab beside browser scripting
  permissions.
- The built-in AI model list adds GPT-6.1 Terra,
  Gemini 4 Argon, and Claude Haiku 5.5.
- The About window has been redesigned, with
  buttons for the home page, bug reports and
  credits, sponsors in a row of cards, and
  backers listed in columns with higher-tier
  backers first.
- The AI Usage gauge in the workgroup toolbar no
  longer shows a Session bar, since Anthropic
  retired session limits. When it can’t read your
  usage it now says why, such as the command
  timing out, instead of just “No usage data”.
- The “Show status in tab subtitle” checkbox in
  the Session Status tool’s settings is now
  “Show status on tabs”. Turning it off hides
  the colored status dot on the tab too, not
  just the status text.
- With the Claude Code Integration, or when the
  Session Status tool follows Codex CLI, a
  session whose turn is over while agents or
  commands it started keep running in the
  background now shows “background” in purple
  instead of “working”, so you can tell at a
  glance that it is ready for input. Issue 13080.
- Recent versions of Claude Code report their
  own status to iTerm2 through the Program Status
  Protocol. The tab now follows those reports,
  and the Claude Code Integration adds what they
  leave out: the “background” status and Claude’s
  last message when a turn is done. Before, the
  two took turns overwriting the tab’s status.
- zsh, fish, and tcsh Shell Integration now mark
  the right-hand prompt, so Select Current Command
  and saved commands leave it out. In tcsh this
  moves the right-hand prompt one column to the
  left.
- Reduced background CPU usage for tracking
  each session’s running job, which previously
  grew with the number of processes running on
  your Mac.
- In beta builds, and for a small share of
  everyone else, each session now handles its
  output independently, so heavy output in some
  sessions no longer makes typing lag in the
  others. If you suspect it of causing a problem,
  search Settings > Advanced for “new
  implementation of session input”, turn that
  setting off, and restart iTerm2. To limit how
  much CPU heavy output can use, set “Sessions
  processing output at once” in Settings >
  General > Magic.
- Drawing text uses less CPU when the GPU
  renderer is off.
- With the Minimal or Compact theme and the tab
  bar on the left or right, the window’s title
  is shown at the top of the tab bar, beside the
  window buttons, window number, or proxy icon,
  even if you haven’t named the window.
- Markdown files shown with imgcat look much
  more like a rendered document: paragraphs
  reflow instead of keeping the file’s line
  breaks, headings are bold with space around
  them, lists hang their text past the bullet or
  number and keep their numbering, code gets a
  background, blockquotes get a bar, tables size
  their columns to fit, and rules span the
  width. Code, quotes, and later paragraphs in a
  list item line up with the item’s text, and
  lists and quotes nest to any depth. Nested
  lists indented with spaces, task lists, tilde
  fences, bare URLs, HTML entities, and
  footnotes are recognized, and links use the
  profile’s link color. Images stored on
  your Mac appear as placeholders; click one to
  see the image in a popover. Images on the web
  are never downloaded and appear as links.
- AI Chat shows Markdown replies the way they
  are meant to look: lists nested with spaces
  are indented, numbered lists can start at any
  number and pick up again after a code block,
  code blocks and quotes inside a list item stay
  with it, quotes nest, task lists show
  checkboxes, and ~~~ code fences are
  recognized.
- With the Rainbow progress bar color scheme on
  macOS 26, a busy tab’s ring now carries a
  rainbow that circles the tab outline instead
  of a band sliding across it.
- On macOS 26, the AI Chat window’s button for
  showing and hiding the chat list is now in the
  toolbar with the model picker instead of
  floating over the conversation.
- Remapped modifier keys now apply in a
  floating hotkey window and in Open Quickly
  while another app is active.
- Smooth-typing animation in Settings >
  Profiles > Text now works with the box cursor
  when GPU rendering is on. Thanks to Brian
  Taylor (@pilotboy72) for the change.
- When a program is reporting mouse clicks,
  holding Option now switches the pointer to a
  plain I-beam right away, showing that clicks
  will select text instead of being reported.
  Issue 13208.
- Updated the SSH and TLS libraries used for
  downloading and uploading files with scp to
  pick up security fixes. Host key prompts now
  show SHA256 fingerprints, the same form ssh
  prints. Servers too old to support RSA
  signatures with SHA-2 (roughly 2016 and
  earlier) can no longer be used with RSA keys.
- Updated the library used to show git status
  to pick up security fixes.
- Updated the syntax highlighter used for text
  files shown inline (for example with imgcat)
  to pick up fixes for patterns that could make
  iTerm2 hang.
- Updated reader mode in the built-in browser to
  pick up fixes for pages that could make it
  hang.

Bug Fixes:
- A sixel image with very large dimensions
  could crash iTerm2’s image decoder or use
  gigabytes of memory. Images with more pixels
  than 8192×8192 are now rejected.
- Fixed a crash when typing a very long word or
  certain unusual characters into the Settings
  search field.
- Fixed a crash on a very long international
  domain name in terminal text.
- Reader Mode and Remove Distractions in the
  built-in browser did nothing when chosen.
  They work again.
- The tooltip for “Enable support for
  right-to-left scripts” in Settings > General >
  Experimental described a tmux setting instead.
- A progress bar from a program that exits
  without clearing it no longer stays up
  forever. It now hides after 15 seconds with
  no update. Issue 13166.
- In tmux integration, a program that asked
  whether iTerm2 supports the Program Status
  Protocol got no answer, so it never reported
  its status there.
- In tmux integration, full-screen programs such
  as htop or vim could show garbled output in a
  zoomed pane after zooming it or resizing the
  window. Thanks to Yifan Gao (@gaoyifan) for
  the fix.
- The Rainbow progress bar color scheme no
  longer shows a hard pink-to-red edge where
  the scrolling band repeats.
- Opening Settings no longer asks for keychain
  access, sometimes several times, to show
  whether an AI API key is set. The keychain is
  read only when you open the Manage AI API Keys
  sheet or start a chat.
- Choosing “Yes” when an app asks to read the
  screen with DECRQCRA is now remembered after
  you restart iTerm2.
- Dragging files from Finder into programs that
  use the Kitty drag-and-drop protocol, such as
  Yazi, no longer bounces back to Finder. Such
  programs also keep accepting drags after
  iTerm2 restarts and restores their session.
- After switching to another user account and
  back with fast user switching, changing or
  removing a hotkey now fully releases the old
  one. Previously the old hotkey kept working
  alongside the new one.
- With fish 4.0.6 or later and its mark-prompt
  feature turned off, Shell Integration recorded
  no commands.
- Commands saved to Command History no longer
  include a right-hand prompt (such as zsh’s
  RPROMPT) drawn on the same line.
- When the shell marked its right-hand prompt
  for iTerm2, a command long enough to reach it
  was saved to Command History with characters
  missing.
- Choosing a command from Auto Command
  Completion could repeat the last character you
  typed (“aws” became “awss”), especially with
  zsh-autosuggestions.
- With the Minimal or Compact theme and the tab
  bar on the right, the window buttons no longer
  permanently cover the top-left corner of the
  terminal or web browser. They now appear when
  you point at the corner, and the window
  number, proxy icon, and window name move to
  the top of the tab bar. If none of them is
  shown, the tab bar no longer leaves empty
  space at its top. Issue 13153.
- Changing a profile’s Profile Type between
  Terminal and Web Browser now leaves open
  sessions that use it as they were, while they
  still receive the profile’s other changes.
  Previously, an open terminal session would
  lose its tab and window names, and changing
  the type back didn’t bring them back.
- Fixed a hang where every window beachballed
  after the Mac sat idle with Claude Code
  running. If macOS was waiting for you to allow
  Claude Code’s status updates to control
  iTerm2, each update piled up behind the
  unanswered prompt until iTerm2 stopped
  responding. Now only one request waits for an
  answer at a time. Issue 13175.
- The offer to try the Claude Code Integration
  no longer appears for claude commands that
  don’t start a session, such as “claude -p” or
  “claude plugin list”.
- Running a coprocess no longer leaves a file
  open each time. After many coprocesses,
  iTerm2 could run out of open files and fail
  to create new sessions.
- With several displays and “Displays have
  separate Spaces” turned on, restoring a
  window arrangement no longer moves its windows
  to the display with the active Space. They
  open where they were saved. Issue 13002.
- Close Other Tabs and Close Tabs to the Right
  now ask before closing tabs with running jobs,
  following Prompt Before Closing. Issue 13185.
- The prompt shown when closing a window or a
  tab with split panes now lists the jobs in
  every pane, not just one of them.
- The Memory Utilization status bar component no
  longer makes macOS log a kernel warning about
  host_statistics64 every second. Issue 13164.
- Restoring a maximized pane after resizing the
  window now fills the window. Before, the panes
  kept their old size, leaving an empty area or
  extending past the window’s edge.
- Dragging a tab to reorder it no longer tears
  it off into a new window or drops it into a
  split pane when the pointer strays a little
  above or below the tab bar. The pointer must
  move about 40 points away from the bar first.
  Issue 13151.
- “Preserve window size when tab bar shows or
  hides” now also applies when the tab bar hides
  after dragging a tab out of a window, and when
  you change “Show tab bar even when there is
  only one tab”.
- After dragging a tab, other windows go back to
  exactly their original size. A window as tall
  as the screen used to end up shorter.
- The Uploads menu no longer pops open while
  “Upload and Paste Path” is uploading and
  pasting. If an upload fails, the menu opens
  once pasting finishes, and now lists files
  that could not be read or folders that could
  not be archived.
- Pressing Esc to cancel a paste that is waiting
  for a shell prompt now also discards
  keystrokes typed while it waited and any
  pastes queued after it. They used to be held
  until the next paste.
- With Reduce Flicker on, or in programs that
  use synchronized updates, part of the screen
  could stop updating until something else
  redrew it.
- Typing at a nushell prompt no longer makes the
  command line blink.
- Programs that change colors with an escape
  sequence, such as tmux when switching to a pane
  whose program set its own cursor color, no
  longer make iTerm2 lag and burn CPU, and no
  longer kick the session out of Copy Mode.
- Find could miss matches in the terminal when
  text shown with Edit > Render Selection
  Natively also matched. The matches were found
  but never highlighted or counted, and Find Next
  and Find Previous stayed stuck on the rendered
  text. A match in rendered text could also drop
  out of Find Next after the first press, and
  text rendered while Find was open was not
  searched. Also, with a command selected, Find
  no longer returns matches from rendered text
  outside that command.
- Selecting a different command while Find is
  open now searches the newly selected command.
  Before, the old results were cleared and Find
  Next had nothing to go to until you retyped
  the search.
- The output saved for a finished command, which
  AI Chat and Codecierge use, could leave off
  its last lines, or start on the wrong line
  when the command spanned several lines or a
  lot of output had scrolled away. They now
  keep at most the last 2,000 lines of a
  command’s output and say how many earlier
  lines were left out.
- The Python API’s GetPrompt could report the
  working directory of a later line instead of
  the prompt’s once output had scrolled off.
- When a shell integration prompt was taller
  than four lines, its text and working
  directory were taken from the wrong line.
- Choosing “Stop Codecierge” in its usage
  warning could stop the pane the toolbelt was
  showing instead of the one that had asked,
  and if the choice was remembered, later
  Codecierge sessions ended silently.
- Ending a Codecierge goal and starting a new one
  before the old goal’s reply arrived could add
  that reply to the new goal’s transcript and
  derail it.
- The Stop Scrolling and Fold trigger actions
  sometimes did nothing when the matching line
  had just arrived.
- When a Fold trigger and another trigger
  matched the same line, the other trigger
  could act on the wrong line.
- After a command was aborted or its prompt
  was cleared away, features that work with
  the most recent command could still refer
  to it.
- AI Chat and Codecierge described a command
  that was aborted, such as by Control-C at
  the prompt, as having succeeded with exit
  status 0. They now say it was aborted.
- When the cache of images drawn with the Kitty
  graphics protocol filled up, it dropped the
  oldest image rather than the one displayed
  least recently.
- The Captured Output tool sometimes didn’t show
  a line a Capture Output trigger had just
  matched, or didn’t clear when a program asked
  it to.
- Session logs could garble text that arrived
  just after a program changed the terminal’s
  character encoding.
- A selection could move to the wrong place when
  a program scrolled part of the screen.
- The auto composer could appear in the wrong
  place when a prompt arrived along with a lot
  of output.
- Double-clicking in a split pane that uses
  mouse reporting while a different pane has
  keyboard focus now reports both clicks to the
  program, so it can recognize the double click.
- In AI Chat, the line above the message field
  no longer seems to float. Messages scrolling
  under the input area are now blurred all the
  way up to the line.
- In AI Chat, a code block whose language name
  has punctuation or capitals, such as ```c++
  or ```Swift, now shows as code. It used to
  show as plain text, and the rest of the reply
  turned into code.
- With GPU rendering and a transparent window,
  underlined text on screen no longer makes all
  the other text look soft or washed out.
- If you installed shell integration with the
  utilities, typing it2ssh could run an old
  copy of it2ssh in ~/.iterm2 instead of the
  one that comes with iTerm2. Shell integration
  now uses iTerm2’s copy when it is available.
- An animated title, such as a spinner, in a tab
  that isn’t selected now keeps moving instead
  of changing only about once a second.
- When one window holds tmux integration tabs
  from more than one tmux session, activity in
  one session no longer switches away from the
  tab you are typing in from another session.
- Closing a window with tmux integration tabs
  and choosing Detach now detaches every tmux
  session in it, even if a non-tmux tab or
  another session’s tab was selected. Closing
  the last tab of one session asks only about
  that session’s windows.
- A custom tab title in one tmux session no
  longer appears on another tmux session’s tab
  after reattaching.
- A hidden tmux window keeps its custom tab
  title, and switching a tmux integration
  client to another session no longer erases
  that session’s custom tab titles.
- iTerm2 Buddy no longer shows AI chat requests
  that already ran as waiting for approval.
  Approving one ran it again and could make the
  chat fail with an error from the AI provider.
- If a terminal session ends while AI chat is
  waiting on a command in it, the chat now
  continues instead of waiting forever.
- New tabs and split panes that reuse the
  previous session’s directory, and the panes
  a Claude Code workgroup opens, could start in
  the directory you were in before your last cd
  if you pasted or typed ahead the commands.
- With tmux integration connected to another
  machine, panes a Claude Code workgroup opened
  outside of tmux could show a notice that their
  directory was unavailable, or start in an
  unrelated directory on your Mac. They now
  start in your home directory.
- In a nested shell, such as bash started from
  zsh or a poetry shell, new tabs and split
  panes that reuse the previous session’s
  directory used the outer shell’s directory
  instead of the one you were in.
- Gestures in Settings > Pointer are now listed
  in a consistent order instead of shifting
  around between visits.
- The announcement offering to pretty-print a
  hard-to-read JSON blob you copied could stop
  appearing without ever being shown, such as
  after copying text that began with a brace
  but wasn’t JSON. Thanks to Kim Dong Han
  (@ehdgks0627) for part of the fix.
- With the Claude Code Integration, agents
  running inside Zellij no longer overwrite each
  other’s Session Status. As with tmux outside
  of tmux integration, iTerm2 can’t tell which
  Zellij tab is showing, so no status is shown.
- Folding a command no longer strips the colors
  from its first line, which mangled prompts
  with colored segments such as powerline
  themes. A folded double-width or
  double-height first line is no longer spaced
  out or drawn at double size.
- On macOS 15 and later, Control-Shift-Arrow
  keys sent nothing to the terminal when the
  Mission Control or Spaces shortcuts were
  enabled.
- With “Quit when all windows are closed” on,
  closing the last tmux window and choosing
  Detach or Kill no longer quits iTerm2 before
  the hidden session that started tmux can
  reappear. Issue 12644.
- After an upgrade or restart, iTerm2 could fail
  to reconnect to running sessions, especially
  when many were open. Each one was replaced by
  a new shell showing a “Session contents
  restored” banner. The fix covers sessions
  created after installing this update, so
  sessions that are already running can still
  be affected the first time you upgrade.
- Fixed a crash when quitting iTerm2, including
  to install an update, while Claude Code was
  running in a session.
- When iTerm2 was busy, typing could lag in
  other apps, especially with modifier
  remapping or a hotkey set. Issue 12645.
- A program that turned on the Kitty keyboard
  protocol in the alternate screen, such as
  Junie CLI, could leave it on for the shell
  after exiting, so keystrokes showed up as
  codes like “99;;99u” and Return did nothing.
  The main and alternate screens now keep
  separate keyboard modes. Issue 13204.
- With ligatures on and GPU rendering, a block
  cursor on part of a ligature, such as the
  second “-” of “--” in Fira Code, no longer
  hides the rest of the ligature. Issue 13203.
- Explain Output with AI could show the wrong
  text as the explanation, or crash, depending
  on how the AI’s reply was laid out. Thanks
  to Kim Dong Han (@ehdgks0627) for the fix.
- Fixed crashes when:
  - launching right after an update;
  - showing a tip of the day;
  - using Undo Close on a hotkey window whose
    profile no longer has a hotkey;
  - a profile or status bar setting held a
    malformed color or font;
  - a profile had an unknown window type;
  - a pointer binding split a pane with a
    profile that had been deleted;
  - an Action selected its own menu item;
  - Claude Code hooks ran at the same moment;
  - an AI chat model had no API key of its own;
  - right-to-left text wrapped at the bottom of
    the screen;
  - a session ended while a disconnection
    message was being shown;
  - entering the alternate screen with an
    annotation that began before the first line;
  - opening the password manager after iTerm2
    was replaced while running.
