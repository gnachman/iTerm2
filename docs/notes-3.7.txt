Version TBD (unreleased; built off master)

Credit to Nimanou (nuved) for the
right-to-left rendering, selection, and copy
improvements in this release.

Major New Features:
- Support for the Program Status Protocol
  (OSC 7501), which lets a program report that it
  is working, waiting on you, done, or failed.
  The tab shows the most urgent status the
  program reported, along with its message and
  progress. A program reporting on several tasks
  at once gets them listed under its session in
  the Session Status tool, and each task that
  needs you can post its own notification.
- Session Status has new “done” and “error”
  statuses for work that finished or failed
  while you were away. They sort just below
  “waiting”, above “working”, and “idle” now
  sorts last. Pressing a key in the session
  marks the result as seen and turns it idle.
  Claude Code and Codex now report a finished
  turn as “done” and an API error as “error”.
  Customized priority lists get the two new
  statuses added below “waiting”, notifying if
  “idle” did.
- iTerm2 is now localized: the interface follows
  your Mac’s language and is available in
  Brazilian Portuguese, German, Japanese, Russian,
  and Simplified Chinese.
- Floating Panes: a pane that floats over a tab’s
  split panes. Create one with Shell > New
  Floating Pane with Current Profile, or with a
  key binding or pointer action. Drag its title
  bar to move it and its edges to resize it. Hold
  Control while dragging to dock it into the
  split panes or move it to another tab or
  window. Window > Floating Panes can raise,
  dock, move and hide them. They are saved with
  window arrangements and can be controlled from
  the Python API. tmux integration shows tmux’s
  own floating panes (tmux 3.7 and later; moving,
  resizing, raising and docking them needs tmux
  3.8).

New Features:
- `it2` can now target a session by the tmux pane
  it is showing. From inside a tmux Integration
  pane, pass --tmux "$TMUX" --tmux-pane
  "$TMUX_PANE" to session set-status, get-status,
  set-var or get-var; a program running there
  cannot otherwise learn which session it is in.
  This works the same on a host reached through
  SSH Integration. (Claude Code’s own status hook
  is not yet installed on remote hosts, so its
  status is only reported automatically for
  sessions on this Mac.)
  Claude Code’s status is no longer reported from
  a pane of a plain tmux session (one not using
  tmux Integration), since iTerm2 cannot tell
  which tab, if any, is showing that pane.
- New `it2 session get-status` prints a session’s
  status indicator as JSON. `set-status` no
  longer requires --session and defaults to the
  active session.
- New Python API functions set_session_status and
  get_session_status read and write a session’s
  status indicator by session ID, and
  session_id_for_tmux_pane finds the session
  showing a tmux pane.
- The Python API can now read, show, hide, and
  update a session’s Session Note.
- The Session Status tool can now follow Codex
  CLI as well as Claude Code. There is no
  installer for Codex yet. Write a small shell
  script that runs the hook program inside
  iTerm2.app (Contents/Resources/utilities/
  cc-status) with the argument --agent codex,
  then in ~/.codex/hooks.json point each event
  at that script and set timeout to 3 on the
  Interrupt and SessionEnd hooks. Codex allows
  those two events one second by default, which
  is not always enough for the hook to finish.
  The status dot then tracks the agent through
  a turn, names what a permission request wants
  to do, clears when you interrupt with Esc, and
  keeps showing work in progress while a
  detached sub-agent runs on after the turn
  that started it. The tab gets a progress
  indicator too, which Codex does not draw for
  itself.
- Right-clicking your own message in AI chat now
  offers Delete, which removes that message and
  everything after it. Edit, Fork, and Delete are
  also available when right-clicking inside the
  message text. Editing or deleting a message now
  also syncs to a paired iPhone viewing the same
  chat (and the phone can delete messages too).
- AI chat can now set a timer to act after a
  delay or at a set time (for example, “in two
  hours, run this command”). The timer survives
  restarts, fires immediately if its time already
  passed, and can push your phone when it fires.
- The Ollama native API type now sizes the
  context window to your prompt so long prompts
  are no longer silently truncated, and the
  chat’s Think toggle now controls whether a
  reasoning-capable local model thinks. Turning
  thinking off makes quick questions fast again.
  There is a new one-click “Ollama (native)”
  model preset, and the API type is now named
  “Ollama.” The manual model editor has a Fetch
  Models button that lists the models installed
  on your Ollama server, and a Vision checkbox so
  image-capable local models can accept images.

- New “Ollama (auto-discover)” model preset: point
  it at your Ollama server and it lists every
  installed model in the picker automatically,
  reading each model’s context window and
  capabilities (thinking, tools, vision) from the
  server. No need to name models or set
  capabilities by hand, and newly pulled models
  show up on refresh.

- Ollama is now a first-class provider in the AI
  model dropdown, alongside OpenAI, Anthropic,
  Gemini, and DeepSeek. Selecting it lists the
  models installed on your local server
  automatically, with no manual configuration. A
  non-local Ollama server is still added as a
  manual model. When Ollama is your default, pick
  which discovered model to use for regular chats
  and an optional smaller one for quick background
  tasks.
- New OSC 1337 codes let a program move and
  resize its window across monitors using global
  coordinates: SetWindowFrame=x;y;w;h sets the
  frame, while ReportWindowFrame and
  ReportScreenFrames report the current frame and
  the layout of all displays. Unlike the older
  CSI 3;x;y t sequence, these are not limited to
  the monitor the window is already on.
- Dragging a tab into a collapsed tab group
  now adds it to that group. The group stays
  collapsed unless you dragged the active tab,
  in which case it expands. While you drag, the
  group's pill highlights to show the tab will
  drop inside it.
- The Python API can now discover and change
  tab groups. A Tab has a tab_group property; a
  Window has tab_groups and can create one with
  create_tab_group; and a TabGroup can be
  renamed, recolored, collapsed, or have tabs
  added or removed. iTerm2 keeps each group's
  tabs consecutive for you.
- The Python API can now run JavaScript in a
  browser session’s page and get the result
  back with Session.async_eval_javascript, so a
  script can read a page or fill in a form
  without clicking on the screen. The first time
  a script does this on a site, iTerm2 asks you
  to allow it. You can review and change these
  permissions, and those for loading URLs, in
  Settings > General > Magic.
- A new “Set Profile Setting” trigger action turns
  a profile checkbox on or off for the session.
  Paired with Job Started and Job Ended matches it
  gives declarative “while this job runs” logic.
- A new “Prevent sleep” profile setting keeps the
  Mac from idle-sleeping while a session with the
  setting enabled exists. Combine it with the new
  trigger action to keep the Mac awake only while
  a long-running job like an AI coding agent runs.
  By default it applies on AC power only; an
  advanced setting extends it to battery.
- You can now press Cmd-F in an AI chat to search
  the current conversation. A find bar appears at
  the top with match counts and next/previous
  navigation; matches are highlighted in place.
  Supports smart-case, case-sensitive, and regular
  expression modes.
- The password manager’s settings menu now offers
  one choice of how often to ask for Touch ID or
  your password: never, once per launch, once per
  launch and after the screen locks, or every
  time it opens. The last option is new, and it
  also closes the password manager when the
  screen locks.
- The Session Status toolbelt tool has a
  snooze button next to the notify button
  that toggles snooze on the selected
  session.
- The built-in web browser can now remember
  HTTP basic-auth user names and passwords.
  Check “Remember this password” in the sign-in
  dialog and it is saved in the browser password
  manager (Keychain, 1Password, and the other
  supported back ends) and offered automatically
  next time. The dialog also has a Password
  Manager button to pick an existing login.
  View or remove saved passwords from the
  password manager.
- ⌘Z now undoes text editing in the field you’re
  editing (the composer, browser address bar,
  annotations, notes, and AI chat), and ⌘⇧Z
  redoes. Undo Close is now solely Shell ▸ Undo
  Close (⌘⇧T). The first time you press ⌘Z with
  a recently closed session still restorable, a
  one-time notice explains the change and lets
  you choose Undo Close or a regular undo.
- New per-profile “Use HDR cursor when
  available” setting (Profiles > Colors). When
  on, a white cursor renders brighter than white
  on an HDR-capable display, with either the GPU
  or the legacy renderer. A slider next to it
  sets how bright the cursor gets. Only sessions
  that enable it pay the extra fp16 cost.
- AI command suggestions can now recognize when
  you have typed a plain-English request instead
  of the start of a command. In that case the
  suggested command replaces what you typed rather
  than being appended to it.
- The Cockpit panel can now send commands from a
  full composer docked along its bottom (the
  same multi-cursor editor, in your profile’s
  font): opening the Cockpit lands the caret
  there. Type @ to pick a session, tab, or
  window from the same picker the AI chat uses
  (with a live preview); it becomes a chip and
  the rest is the command, sent verbatim. Return
  inserts a newline and Shift-Return sends.
  Mentions and the outline selection stay in
  sync: selecting a session, tab, or window row
  adds the matching chip (a tab or window chip
  fans out to all its panes), and editing chips
  reselects the rows. A status line under the
  composer confirms the count. The list and
  composer are resizable split panes and the
  list is a rounded inset card.
- The it2 command-line tool can now send a push
  notification to your paired companion device
  with “it2 notify «title» «body»”.
- The window name can now appear beside the tabs
  in the Compact and Minimal themes, which have
  no title bar to show it in. By default it
  appears only once you name a window with
  Window > Edit Window Title, so windows you have
  not named look exactly as before. Double-click
  the name to rename the window. The advanced
  setting “Show the window name beside the
  tabs” can turn it off or always show it.
- The workgroup toolbar can show an AI Usage
  gauge with your Claude subscription’s session
  and weekly usage as progress bars. Add it to a
  session’s toolbar in the workgroup settings and
  choose how often it refreshes; it reads the
  numbers by running the Claude Code command-line
  tool. You can point it at your own command
  instead.
- There is a new “Centered, No Title Bar”
  window style, in Settings > Profiles > Window >
  Style and in the Window > Window Style menu. It
  stays centered on the screen like the Centered
  style but has no title bar or window controls,
  which is how Centered windows looked before
  3.7.0.
- Window > Lock Location pins a window to the
  display and position it has when you turn it
  on. If anything moves the window it goes right
  back, and when that display is disconnected, as
  happens while a laptop sleeps, the window waits
  and returns when the display comes back.
  Dragging the window turns the lock off. Styles
  that fill or attach to the screen, such as
  Maximized, Centered, and the top, bottom, left,
  and right styles, keep their usual shape and
  are held to their display instead. Note that
  macOS puts a returning window on whichever
  Space its display is showing at the time, which
  may not be the Space it left.
- A session status can now be told when it
  stops being true. Along with the status,
  a program says what the status should
  become once the work it describes is
  over, and iTerm2 makes the change when
  the program reports that the work
  finished. It keeps a status from
  outliving the thing it was reporting on
  when a program is stopped partway
  through. Set it with the --expires-on
  option of it2 set-status, or the
  expires_on argument of the Python API’s
  set_status.
- Each profile can now choose what its bell
  sounds like, in Settings > Profiles > Terminal >
  Bell sound. Pick one of the sounds installed on
  your Mac or choose “Other…” for any audio file
  of your own, and give noisy sessions a bell you
  can tell apart from the rest.
- Apps can now control right-to-left text
  reordering with the BDSM and SCP escape
  sequences. CSI 8 l enters explicit mode,
  in which text is drawn exactly as written,
  and CSI 8 h returns to implicit mode. This
  keeps full-screen apps that lay out their
  own text from being scrambled. CSI 1 SP k
  and CSI 2 SP k make reordered lines
  left-to-right or right-to-left, and
  CSI 0 SP k restores the default.
- New variables iterm2.workingSessionCount and
  iterm2.waitingSessionCount count the sessions
  whose status reads “working” or “waiting”. Use
  them anywhere interpolated strings work, such
  as badges, tab titles, and the status bar.
- New setting in Settings > Appearance > General
  shows an iTerm2 icon in the menu bar, optionally
  followed by an interpolated string such as
  \(iterm2.workingSessionCount).
- You can hide a browser session’s toolbar so the
  page fills the pane with Web > Show Toolbar, or
  from the Python API with
  Session.async_set_browser_toolbar_hidden.
- nushell is now a supported shell for shell
  integration, including automatic loading and
  SSH integration.

Improvements:
- Pausing a spinning progress indicator with
  OSC 9;4;4 now shows a paused spinner: a still
  yellow band in the session and a pause symbol
  in the tab, instead of a yellow bar at 10%.
- Python API context menu items can be grouped
  into submenus and shown only in sessions where
  an expression is true, such as a user variable
  your script sets. See ContextMenuProviderRPC’s
  submenu and visible_when arguments.
- If a profile archives sessions when they close
  (Settings > Profiles > Session), Undo Close
  keeps working after its time limit runs out.
  Archived sessions come back from their archives
  in their original split panes, tabs, and
  windows. The last 20 can be undone even after
  restarting iTerm2.
- The built-in AI model list is up to date. It
  adds GPT-6 Astra, GPT-6.1 Sol, GPT-6 Sol,
  GPT-6 Luna, GPT-5.4 Pro, GPT-5.4 mini, Gemini
  3.8 Flash, DeepSeek Flash (V4.1), Claude Opus
  5.5, Claude Sonnet 5.5, Claude Fable 5.1,
  Claude Opus 5, and Claude Fable 5, and the
  recommended model for each provider is now its
  newest flagship. Newer Claude models also get
  their full 1 million token context window.
  o4-mini, which OpenAI is shutting down, has
  been removed.
- iTerm2 now recognizes when a terminal is
  running on your own Mac by machine identity
  rather than by hostname, so features that only
  work locally keep working over a VPN or
  Tailscale connection where the hostname no
  longer matches. Reinstall shell integration
  (iTerm2 > Install Shell Integration) to enable
  this.
- The Move Tab Left and Move Tab Right shortcuts
  now move just the current tab instead of its
  whole tab group. Moving a tab past the edge of
  its group pops it out of the group, and moving
  an ungrouped tab into a neighboring group adds
  it to that group.
- A warning that iTerm2 shows while you are away
  from your Mac no longer cuts off your paired
  iPhone. The iTerm2 Buddy app stays connected,
  shows the warning, and lets you answer it,
  including “don’t ask again” and password
  prompts (a password manager’s master password,
  an scp password). Other kinds of
  dialogs can’t be answered from the phone, but
  it now says the Mac is waiting instead of
  appearing disconnected. Requires an up-to-date
  iTerm2 Buddy.
- Pairing a companion iPhone no longer requires
  AI. The setup wizard (iTerm2 > Companion Device
  Settings) now lets you choose “Terminal viewing
  & control only”, so you can browse sessions,
  watch live output, and type from your phone
  without an AI plugin or API key. Chat features
  appear disabled with an explanation until you
  turn AI on.
- The Companion setup wizard no longer asks for
  an API key when AI already works, or when you
  chose a model manually in Settings > General >
  AI. If that model isn’t set up yet, the wizard
  says so and lets you finish setup anyway.
- Reduced idle CPU usage that previously grew
  with the number of open windows.
- AI command safety checks now prefer the cheaper
  "economy" model when one is available, so the
  frequent low-stakes safety side-query costs
  less. It falls back to your configured model
  when no economy model exists.
- Custom HTTP headers for AI requests are now
  set per manual model in the model editor,
  not one global list, so each endpoint can
  send its own auth header. This lets an
  authenticated self-hosted / local endpoint
  work by adding its Authorization header.
  Existing global headers are copied to your
  saved models. The editor also shows which
  API key (if any) each model uses. Issue 12975.
- The manual AI model editor has a new API key
  setting. It can send one provider’s stored
  key, a key entered just for that model, or no
  key. Automatic, the default, shows which key
  it picked, and sends a provider’s key only to
  that provider’s own servers: a gateway such
  as OpenRouter no longer gets your OpenAI key
  unless you choose it. Models you already set
  up keep sending the key they sent before.
  This also helps with gateways like Open WebUI
  whose model names mention another provider
  (such as “gemini/…”). Issue 13105.
- Settings search now reveals controls that live
  on an inner sub-tab (such as AI > Features). It
  switches to the correct nested tab before
  highlighting, instead of dimming a bogus area.
- Hidden hotkey windows no longer redraw
  at the full active cadence. Sessions
  with continuous output (builds, tails,
  agents) in a hidden hotkey window used
  to burn CPU and GPU rendering frames
  nobody could see, spinning fans on
  laptops. Hidden windows now drop to
  the background refresh rate and repaint
  the instant they are revealed.
- The AI timeout is now an idle timeout (the
  maximum gap between bytes received) rather
  than a cap on the total time a request may
  take. A slow but healthy generation, such as
  a reasoning model that is still thinking or a
  cold local model, keeps running as long as it
  makes progress, while a dead connection still
  fails. The default was also raised to 20
  minutes. This fixes spurious timeouts against
  local Ollama servers.
- The Interpolated String status bar
  component now shows [undef: x] for a
  reference to an undefined variable
  instead of silently rendering an empty
  string, making typos and unavailable
  variables obvious. Use \(x?) to treat a
  missing value as empty.
- The Current Directory status bar
  component’s folder icon is now a proxy
  icon: drag it to another app to drag the
  session’s working directory, like the
  proxy icon in a window title bar.
- The tab group rename and creation dialogs now
  match the light/dark appearance of their
  window in the minimal theme.
- Browser tabs now show a title (page title, or
  the host, or the profile name) instead of a
  blank tab and window title.
- In the minimal theme, a browser tab's light or
  dark appearance and tint now follow the page's
  background color instead of the profile's
  terminal background color.
- The Cockpit shows each session's live status in
  every grouping: the session's own status word
  (whatever it reports, in its own color) and the
  detail line now appear in Window and Workgroup
  views too, not just Status. A filter bar along
  the top narrows the list to any one status,
  with live counts; the status list is dynamic,
  so arbitrary statuses from any tool just work.
  Window/tab/session rows also carry the matching
  macwindow / folder / terminal icon.
- Duplicate Tab now opens the copy immediately to
  the right of the original tab instead of at the
  end of the tab bar. There is a new advanced
  setting, “When you duplicate a tab, should the
  copy open immediately to the right of the
  original tab?”, if you prefer the old placement.
- The git branch shown in the session
  toolbar can now be right-clicked to copy
  its name, or dragged into a text field to
  paste it (or dropped on the Finder as a
  text clipping). Available only while a
  branch name is showing, not during a
  rebase or similar.
- With the tab bar on the left or right, the tab
  and tab group context menus now say “New Tab
  Below” and “Close Tabs Below” instead of “to
  the Right”, matching the direction the tabs
  actually run. The confirmation for closing the
  tabs after a group follows suit.
- Dropping a text file into a session connected
  to a remote host now offers Paste as Text,
  which types the file’s contents into the
  terminal. Previously only the upload options
  and Paste Base64-Encoded Contents were offered
  there.
- Dropping several files into a session
  connected to a remote host now offers “Upload
  and Paste Paths”, which uploads them all and
  then types their remote paths onto the command
  line, as the single-file case already did.
  Files that fail to upload are left out of what
  is pasted. Local paths are no longer offered
  there, since they name nothing on that host.
- Fixed a source of main-thread stalls that built
  up in windows left open for days.
- The Snippets tool no longer rebuilds its list
  every time you switch tabs or the running
  command changes, which had been making windows
  slowly get slower the longer they stayed open.
  The Jobs tool had the same problem when you
  switched tabs, and is fixed too.
- “it2 session list” takes a --format option: an
  interpolated string evaluated in each session,
  such as '\(session.path)'. It prints one line
  per session, or with --json adds the result to
  each session as “formatted”. This lists every
  session’s directory or job in one command.
- Uploads over SSH Integration are about three
  times faster.
- “Upload and Paste Path” now works in tmux
  integration windows reached through SSH
  Integration, and before shell integration has
  reported a directory, in which case the file
  goes to your home directory.
- Pasting a screenshot with “Upload and Paste
  Path” converts TIFF images to PNG and gives
  each one a unique name.
- The Script Console now keeps only the 200 most
  recent finished scripts and API connections.
  It used to keep every one, and tools that
  connect for each command, like it2, piled up
  enough of them to slow iTerm2 down over time.
- Focus Follows Mouse no longer takes focus
  away from the find bar, composer, or other
  fields in a pane by accident. To have focus
  follow the pointer onto those views and back
  onto the terminal, turn on “…even to views
  like Search or Composer” under Settings >
  Pointer.
- Right-clicking a tab now offers Rename Tab,
  which opens the same dialog as double-clicking
  the tab.
- The Python API now has type annotations, so
  editors and type checkers such as mypy can
  check scripts that use it.

Bug Fixes:
- With KeePassXC as the browser password
  manager, “Remember this password” for a
  website’s sign-in dialog now saves the
  password instead of failing with “Could not
  save the password”.
- In the Add/Edit Manual AI Model sheet, the
  API key menu is no longer too narrow to show
  “Automatic (none for a local endpoint)”.
- On macOS 26, hiding a hotkey window when no
  other iTerm2 windows are open once again
  returns focus to the previous app right away,
  so text you type immediately afterward no
  longer goes to the terminal.
- Fixed a crash with the GPU renderer that
  could happen when switching to or from
  battery power.
- Fixed a crash from a Smart Selection rule
  with no regular expression, for example in a
  hand-edited or Dynamic Profile.
- Fixed memory corruption with the GPU renderer
  that could cause crashes after closing a
  session.
- Fixed a crash when iTerm2 was told to quit,
  for example by logging out, while it was
  still starting up.
- Fixed a crash when opening a new tab with a
  profile whose font could not be measured.
- Fixed a crash that could happen after closing
  a tab while an accessibility app, such as
  VoiceOver, was in use.
- Fixed a crash when splitting a pane that was
  closed or moved to another window before the
  split finished.
- Fixed crashes loading Dynamic Profiles files
  with values of an unexpected type, such as a
  null value or a Keyboard Map that is not an
  object. These values are now ignored or
  reported instead.
- Fixed a crash when holding Cmd with the mouse
  over a gray autosuggestion in the composer.
- Fixed a crash when exiting full screen in a
  window without a title bar, such as a tmux
  integration window, on macOS 26.
- Fixed a crash when splitting, maximizing,
  swapping, or rearranging panes in a tmux
  integration window that was left open after
  detaching.
- In tmux integration, a layout change made by
  tmux while Find > Filter was open on a pane no
  longer hides pane %0 or moves keyboard focus
  away from the filtered pane.
- Answering “Always” to “Close tmux windows
  after detaching?” now closes only the tmux
  integration windows left open by the detach.
  It used to close every session in the app.
- tmux integration no longer disconnects when a
  window has only floating panes (tmux 3.8 and
  later), and tolerates commands that fail
  because of a floating pane.
- Closing an archived session soon after opening
  it no longer warns that the session ended very
  soon after starting.
- Archiving split panes with the same name when
  their window closes no longer saves only one of
  them.
- Sessions closed shortly before quitting are
  now always archived if their profile archives
  sessions on close.
- iTerm2 no longer crashes when its app was
  moved, deleted, or replaced while running,
  for example by an installer. It now explains
  that the app is damaged and quits.
- Fixed “Export All Settings and Data” failing
  with “Failed to copy file” after using SSH
  Integration. Temporary connection files it
  could not copy are now skipped.
- Fixed a crash in “Import All Settings and
  Data” when the import changed a setting that
  requires your administrator password.
- Fixed a crash with the GPU renderer that
  could happen after changing the font size
  with Cmd-+ or Cmd--.
- Fixed a crash that could happen after using
  Find when the window got narrower before the
  match was highlighted.
- Fixed a crash that could recur every time
  iTerm2 saved window state. Quitting while a
  save was in progress could store duplicate
  entries in the saved-state database, which
  later saves could not handle.
- The crash reporter’s message fills in your
  name again instead of showing %%LONGUSERNAME
  and %%EMAILADDRESS.
- Fixed Tab.async_update_layout in the Python
  API making a browser pane many times too big,
  squeezing the panes beside it, and sometimes
  crashing iTerm2.
- Pasting or dropping a file or image into a
  local tab no longer offers only to upload it
  when another tool in your shell (such as
  oh-my-zsh) reports an outdated host name. When
  iTerm2 can’t be sure a session is on another
  machine, the paste dialog now also offers to
  paste a local path.
  Issue 13117.
- Make Text Bigger works again when you type it
  as ⌘⇧= (the way you type ⌘+). Since 3.7.0,
  that keystroke opened the Clippings panel
  instead, because Show Clippings had claimed it.
  Show Clippings is now ⌘⇧⌥G. Issue 13022.
- “Open Selection as URL” now works on links
  without a scheme, like example.com/path, and
