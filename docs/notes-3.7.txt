Bug Fixes:
- Fixed a security issue where a crafted file,
  when displayed in the terminal (for example
  with “cat”), could run arbitrary commands by
  abusing the Kitty image protocol’s file
  transmit feature. Error responses no longer
  include control characters that could be
  injected into your shell. Thanks to Minseong
  Kim of NSHC Red Alert Labs for the report.
