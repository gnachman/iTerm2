Version 3.7.4

Bug Fixes:
- Fixed a crash that could recur every time
  iTerm2 saved window state. Quitting while a
  save was in progress could store duplicate
  entries in the saved-state database, which
  later saves could not handle.
- Fixed a crash when opening a new tab next to a
  tab in a tab group.
- iTerm2 no longer crashes when its app was
  moved, deleted, or replaced while running,
  for example by an installer. It now explains
  that the app is damaged and quits.
- Fixed a crash when exiting full screen in a
  window without a title bar, such as a tmux
  integration window, on macOS 26.
- Fixed a crash with the GPU renderer that
  could happen after changing the font size
  with Cmd-+ or Cmd--.
- Fixed a crash that could happen when the GPU
  renderer had been running for several weeks
  without restarting iTerm2. Issue 13103.
- Fixed a crash when pressing Cmd-Z after
  closing a pane, toolbelt tool, or other view
  that had text you had edited.
- Fixed a crash when a program printed a
  letter followed by many spacing marks (such
  as Devanagari vowel signs) in a later write.
  Issue 13073.
- Fixed a crash in “Import All Settings and
  Data” when the import changed a setting that
  requires your administrator password.
- Fixed “Export All Settings and Data” failing
  with “Failed to copy file” after using SSH
  Integration. Temporary connection files it
  could not copy are now skipped.
- Fixed crashes loading Dynamic Profiles files
  with values of an unexpected type, such as a
  null value or a Keyboard Map that is not an
  object. These values are now ignored or
  reported instead.
- Fixed a crash, repeated on every relaunch,
  when a profile’s name began with a combining
  mark.
- Fixed various other crashes, including ones
  involving Find, the composer, splitting
  panes, Smart Selection, right-to-left text,
  VoiceOver, the GPU renderer, and quitting
  while iTerm2 was still starting up.
- Pressing space twice in a terminal no longer
  types a period when macOS’s “Add period with
  double-space” setting is on. In vim this could
  repeat your last command. Issue 13123.
- iTerm2 no longer applies macOS’s automatic
  spelling correction, capitalization, or smart
  quotes and dashes. They could change what you
  type in a terminal. Text replacements still
  work.
- Make Text Bigger works again when you type it
  as ⌘⇧= (the way you type ⌘+). Since 3.7.0,
  that keystroke opened the Clippings panel
  instead, because Show Clippings had claimed it.
  Show Clippings is now ⌘⇧⌥G. Issue 13022.
- Help popovers, such as the ones shown by the ?
  buttons in Settings, no longer cut off the last
  line of text, and no longer scroll when all of
  their text fits.
