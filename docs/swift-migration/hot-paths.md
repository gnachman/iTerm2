# Hot paths

Part of the Objective-C to Swift migration process. Read
[README.md](README.md) first.

Units deferred until everything else is done, under
[performance.md §2](performance.md), each with the reason. A unit that turns
out to be a hot path while being worked on is added here, its claim is
dropped, and work moves on. Anything in a hot path needs the owner before it
is started ([workflow.md §3](workflow.md)).

The inventory script defers whole directories that
[performance.md §2](performance.md) names; `inventory.py leaf` prints them
with the reason. This file lists the units found to be hot paths in addition
to those.
