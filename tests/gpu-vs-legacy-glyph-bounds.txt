Set Profiles > Text > Anti-aliased OFF, or none of this exercises the change.
Every pair of lines below must look identical with and without GPU rendering.

Fonts worth trying, and what each one stresses:
  Monaco 12 or 9, on a NON-Retina display -- the reported bug itself (~).
  Source Code Pro / Sauce Code Pro NFM 10-16 -- worst affected here (% and ").
  PT Mono Bold 13-16 -- " at both backing scales.
  JCsmPC 9-12 -- the largest error found (< and >).
  Cascadia Code PL 14 or 16 -- backtick.
  Berkeley Mono, Monaspace, CommitMono NF, Hasklug, Fira Mono NFM and
  Operator Mono Bold report bounds in font design units when antialiasing
  is off, so they exercise the fallback path.
