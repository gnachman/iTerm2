[1mยินดีต้อนรับสู่ Python REPL ของ iTerm2[m

นี่คือตัวแปลภาษา Python แบบโต้ตอบที่คุณสามารถใช้ทดลองสคริปต์ได้
คุณสามารถใช้ “await” นอกฟังก์ชัน async ได้ ซึ่งต่างจากตัวแปลภาษา Python
ทั่วไป ลองใช้สคริปต์ตัวอย่างนี้:

import iterm2
connection=await iterm2.Connection.async_create()
await iterm2.Window.async_create(connection)
