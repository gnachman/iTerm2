[1mSelamat datang di REPL Python iTerm2![m

Ini adalah interpreter Python interaktif tempat Anda dapat bereksperimen
dengan skrip. Tidak seperti interpreter Python standar, Anda dapat
menggunakan “await” di luar fungsi async. Berikut contoh skrip untuk
dicoba:

import iterm2
connection=await iterm2.Connection.async_create()
await iterm2.Window.async_create(connection)
