[1mBienvenue dans le REPL Python d’iTerm2 ![m

Cet interpréteur Python interactif vous permet d’expérimenter avec des
scripts. Contrairement aux interpréteurs Python standard, vous pouvez utiliser
« await » en dehors d’une fonction asynchrone. Essayez ce script d’exemple :

import iterm2
connection=await iterm2.Connection.async_create()
await iterm2.Window.async_create(connection)
