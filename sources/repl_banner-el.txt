[1mΚαλώς ορίσατε στο Python REPL του iTerm2![m

Αυτός είναι ένας διαδραστικός διερμηνέας Python όπου μπορείτε να
πειραματιστείτε με σκριπτ. Σε αντίθεση με τους τυπικούς διερμηνείς Python,
μπορείτε να χρησιμοποιήσετε το «await» και εκτός συνάρτησης async.
Ακολουθεί ένα παράδειγμα σκριπτ για να δοκιμάσετε:

import iterm2
connection=await iterm2.Connection.async_create()
await iterm2.Window.async_create(connection)
