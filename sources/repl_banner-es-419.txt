[1m¡Te damos la bienvenida al REPL de Python de iTerm2![m

Este es un intérprete interactivo de Python en el que puedes experimentar con
scripts. A diferencia de los intérpretes de Python estándar, puedes usar
“await” fuera de una función asíncrona. Prueba este script de ejemplo:

import iterm2
connection=await iterm2.Connection.async_create()
await iterm2.Window.async_create(connection)
